# Music files of the promotional videos

This folder holds the two music files of the video `video_game_first`. Git ignores the music files, because the license does not allow to redistribute a music file alone. Git keeps only this `README.md`.

## Files

| File | Use in the video | Source |
| --- | --- | --- |
| `echoes_of_lumen-epic-background-music-595722.mp3` | The intro. It fades out with the splash screen. | https://pixabay.com/music/adventure-epic-background-music-595722/ |
| `vadim_makes_sound-podcast-outro-music-551266.mp3` | The outro. The video ends at the last silence of this music. | https://pixabay.com/music/lofi-podcast-outro-music-551266/ |

To get a file again, open the source page, press the download button, and save the file with the name in the table.
