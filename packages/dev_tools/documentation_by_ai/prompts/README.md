# Maintained prompt

learned_prompt.md is the authoritative writing prompt for this package. documentation_prompt.ts adds the current scope, input paths and run record path. Editing this prompt changes future requests; it does not trigger generation.

provenance.json records the source module fingerprint and the historical calibration copies. The learned style was carried forward from the experiment and adapted to the developer's explicit one-generation/one-build stopping point. Old automatic comparison, outline, judge and visual-review stages were deliberately excluded. Current glossary directories and source inventory replace historical paths and snapshots. The package does not depend on the temporary worktree at runtime.
