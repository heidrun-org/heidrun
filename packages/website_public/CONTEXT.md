# Directory Context: `/packages/website_public`

## Purpose
The public website of Heidrun: a homepage and the user documentation, built with VitePress and published on GitHub Pages with the script `ghpage:deploy`.

## Key Exports & Entry Points
- `docs/`: the Markdown source of the website. `docs/index.md` is the homepage. `docs/documentation/` holds the documentation pages.
- `docs/.vitepress/config.ts`: the VitePress configuration (title, navigation, sidebar, `base`).
- `tests/`: the Vitest tests of the website (configuration, pages, shortcuts page, splash image, complete build).
- Command to run this folder: `pnpm --filter website_public dev`
- Command to test this folder: `pnpm --filter website_public test`

## Rules
- The `base` option in `docs/.vitepress/config.ts` equals the GitHub Pages path of the repository (`/heidrun/`).
- Nothing in this folder imports from another package of the workspace.

- The page `docs/documentation/shortcuts.md` is generated by `pnpm docs:shortcuts`: its text has no raw angle bracket, because VitePress reads `<agent>` as a Vue tag and the build fails.
