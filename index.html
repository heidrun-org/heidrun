Who is Heiðrún?

One work window

A tab bar above the panes, the workspace selector in the status bar, and the queue of agents that are blocked or finished in the right sidebar.

Real terminals

Each pane shows the real Herdr terminal, so Claude Code, Codex, and the colors look the same as in Herdr.

Macros

One click writes a ready text into the terminal of a pane. The agents never wait for a developer who is typing.

Inspector

Allow or deny an agent request, read the context of an agent, and ask another agent to fix a problem.

Quotas in view

The status bar shows the Claude quotas (5 hours and week) and the Codex quotas. The mead never runs out by surprise.

Command palette

Press ⌘K for every action. A real Viking does not use the mouse.
