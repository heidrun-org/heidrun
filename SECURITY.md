# Security Policy

Even Valhalla has a gate to guard. Heidrun can reach your terminals, your agents, and, with the mobile access feature, your phone. We take security seriously.

## Supported versions

Only the latest version of Heidrun receives security fixes.

## Report a vulnerability

Do **not** open a public issue for a vulnerability. A public report gives the trolls a map.

1. Go to the [Security tab](https://github.com/heidrun-org/heidrun/security) of the repository.
2. Choose "Report a vulnerability" to open a private report.
3. Describe the problem: what you did, what happened, and which version of Heidrun and macOS you use.

If you cannot use the Security tab, contact the maintainer [Jérôme Étienne](https://github.com/jeromeetienne) through GitHub and ask for a private way to send the report.

## What happens next

- We confirm that we received the report.
- We investigate, and we keep you informed.
- We publish a fix, and we thank you in the release notes if you want.

## Good to know

The mobile access server listens only on the Tailscale address of the Mac, and each request needs a pairing key. A report that shows a way around these protections is very welcome. The mead stays inside the cauldron.
