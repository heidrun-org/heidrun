This file lists the files and the subfolders of this folder, for agents and tools.

- [README.md](README.md): the overview of this folder, for people.
- [inputs.md](inputs.md): the three inputs that connect the code to the work that produced it.
- [inputs_links.md](inputs_links.md): how a chat session, a commit, an issue, and a pull request link to each other in the SQLite file of the data layers, how complete each link is on this repository, and the known gaps.
- [metrics_rules.md](metrics_rules.md): what a metric of this folder is, what it is not, the seven tests that evaluate a metric, how to write a new one, and the prompt that makes a coding agent discover new metrics.
- [metrics_examples.md](metrics_examples.md): the ten metrics that the join of the three inputs gives, each with its definition, its SQL query, its result on this repository, and its limits.
