This folder holds one generated PNG illustration for each article. The illustrations share an ink-and-gouache editorial style with dark blue, ivory, amber, and teal. These images are editorial artwork, not product screenshots or measured charts.

Use the matching illustration at the end of the first article section and as the attachment to the article's social message. Read [prompts.md](prompts.md) for the generation method and final prompts.
