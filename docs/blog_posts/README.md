This folder holds three draft articles for developers who may become early users of Heidrun. Read the articles in the order below. The series introduces daily use, reconstructs a real engineering decision, then examines a defined week of development.

1. [Three Features in Progress. Which One Needs Me?](three-features.blog_post.md)
2. [Why Did We Write This Code? Ask the Development History](development-history.blog_post.md)
3. [What Does a Day of Development With Coding Agents Actually Look Like?](day-of-development.blog_post.md)

The [series plan](blog_series_plan.md) preserves the interview decisions and the required process URL. The [evidence](evidence.md) records the sources, scope, queries, and limits of the articles. The [social messages](social_messages.md) reuse each article's illustration. The [image prompts](images/prompts.md) record how the illustrations were generated.

The developer asked to keep all three personal-blog copies as drafts. The [import instructions](personal_blog_import.md) explain the imported copies and how to review the imported pages locally. No publication dates have been chosen.
