This folder holds the rules of the Chats sidebar section.

Read `chats_list.md` for the list of chats, `chats_header_and_sort.md` for the buttons at the top and the sort menu, and `chat_summary.md` for the three lines of the summary of a chat. The folder `information_cards` covers the information cards, and the folder `dynamic_topics` covers the dynamic topics.
