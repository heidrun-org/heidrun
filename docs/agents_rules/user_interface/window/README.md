This folder holds the rules of the window of Heidrun: its layout, its colors and scroll bars, its abbreviated times, its status bar, its position and size, the Statistics window with its two tabs, the Guards section of the Settings window, the information card of every option of the Settings window, the Voice input section of the Settings window, and the window "Find new skills".

Start with `layout.md`, which gives the layout of the whole window. Each other file covers one part of the window.

Read [shared_design.md](shared_design.md) before changing colors, buttons, or status displays; the file connects the rules to their shared implementation and checks.
