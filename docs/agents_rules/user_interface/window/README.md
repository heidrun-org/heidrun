This folder holds the rules of the window of Heidrun: its layout, its colors and scroll bars, its abbreviated times, its status bar, its position and size, and the Statistics window with its two tabs.

Start with `layout.md`, which gives the layout of the whole window. Each other file covers one part of the window.
