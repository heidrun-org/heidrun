This document gives one short definition for each word of the search in the Code hosting sidebar section. The other words of Heidrun are in [glossary.md](glossary.md).

### Search field

The text field above the two lists of the Code hosting sidebar section. The developer writes a search in the search language of GitHub, and presses the key Enter. The two lists then show the items that match the search. An empty search shows all the open items.

### Saved search

A search that the developer keeps under a name, for example "Mine" for `author:@me`, or "Mentions me" for `mentions:@me`. The Code hosting sidebar section shows each saved search as a small button under the search field. A click on the button fills the search field and runs the search. A saved search is the same in every workspace, and Heidrun keeps it with the other options. A saved search is saved in the window "Save this search", and renamed, changed, or deleted in the window "Edit the saved search".

## Rules

- Write "saved search" in full. Do not write "bookmark", "favorite", "preset", "filter", or "view" for it.
- Write "search field" in full. Do not write "search box" or "query box" for it.
