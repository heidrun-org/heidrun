# Glossary of Heidrun

- Created: 14 October 2026
- Last updated: 14 October 2026
- Status: Maintained overview for people
- Related framing: [Project instructions](../../../AGENTS.md)
- Related issue: [issue 405](https://github.com/heidrun-org/heidrun/issues/405)

This folder holds the glossary of Heidrun: one short definition for each word that the project uses for a part of the application. Use these words, and no other word, in the code, in the documents, and in the conversations. One word means one thing, and one thing has one word.

The glossary is split by topic into small files. Read only the files that match the part that you change. The file `index.md` lists them.
