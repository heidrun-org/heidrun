This document gives one short definition for each word of the search in the Code hosting sidebar section. Each list of the section, "Issues" and "Pull requests" (or "Merge requests"), has its own search. The other words of Heidrun are in [index.md](index.md).

### Search line

The line under the title of a list of the Code hosting sidebar section. It holds the search field, then three buttons that show only an icon, on the same line: "Search", "Save this search", and "Edit the saved search". Each list has its own search line.

### Search field

The text field of a search line. The developer writes a search in the search language of GitHub, and presses the key Enter. The list of this search line then shows the items that match the search, and the other list does not change. An empty search shows all the open items of the list.

### Saved search

A search that the developer keeps under a name, for example "Mine" for `author:@me`, or "Mentions me" for `mentions:@me`. The Code hosting sidebar section shows each saved search as a small button under the search line of its list. A click on the button fills the search field of this list and runs the search in this list. A saved search belongs to one list: a saved search of the list "Issues" never shows in the list "Pull requests". A saved search is the same in every workspace, and Heidrun keeps it with the other options. A saved search is saved in the window "Save this search", and renamed, changed, or deleted in the window "Edit the saved search".

## Rules

- Write "saved search" in full. Do not write "bookmark", "favorite", "preset", "filter", or "view" for it.
- Write "search field" in full. Do not write "search box" or "query box" for it.
- Write "search line" in full. Do not write "toolbar", "search bar", or "search row" for it.
