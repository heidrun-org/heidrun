## What is new in 0.3.0

- The new Heidrun Mobile website lets you use Heidrun from a phone, through an ngrok tunnel with a fixed address and a QR code. It has the launchers, the microphone, the macros, the terminals, and the notifications.
- Voice input is new and optional. You speak with a push-to-talk button, and a local Whisper model changes your voice into text. Heidrun tells you when another pane uses the voice input.
- The composition bar under the focused pane stays open after Send, keeps its draft with each pane, accepts a drop of images, and has a Settings option for its start with each coding agent.
- Each pane can move by drag and drop, inside its tab and to another tab. Zen Mode helps you to work with focus, and the buttons of the header of a pane appear only while the pointer is over the pane.
- A file that you click in the File explorer opens in a new read-only file view pane, with the front matter in a card. The File explorer also browses the Git submodules, and Heidrun browses the Git worktrees of a repository and opens a workspace from one of them.
- The Statistics window remembers your selections. The tab "Work of one person" shows the lines added and deleted, the commits or the pull requests, and the AI cost in US dollars or in tokens, for one workspace or for several workspaces.
- The Settings window has eight sections, and every option has a circled question mark that opens an information card. New options are the Text detection section, the Guards section, and a goat sound. Heidrun keeps your saved options when it updates.
- The Code hosting sidebar section has a search line in each list and a button that copies the web address of an issue or a pull request. The Source control sidebar section has distinct icons for the discard buttons.
- The command line tool `heidrun_data` answers questions about the history of a repository, the past chats, the memory files, the skills, and your activity. The command line tool `heidrun_ctrl` changes the macros, the launchers, and the workspaces of a running Heidrun. Heidrun installs both, with their skills, for your coding agents.
- The coding agent Antigravity is supported everywhere, Codex works in the light theme, and Heidrun keeps your coding agents running after you quit. Heidrun reads the `PATH` of your login shell, so the installed Heidrun finds `gh`.
- A copy of wrapped text in a terminal keeps the command lines whole, and a shell command that a coding agent wrote on several lines runs as one whole line.
- The installed Heidrun has a new application identifier, `dev.heidrun-org.heidrun`, and needs macOS 11.0 or later. The website has a new homepage, and the script `scripts/install.sh` installs the latest release with one command.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
