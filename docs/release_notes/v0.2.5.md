## What is new in 0.2.5

- The sidebar has three new sections: Chats, Source control, and Files. The Chats section can show dynamic topics, extracted with keywords or with a language model, and it has a sort menu.
- The status bar has a workspace selector, a Git branch picker, and a synchronization button for the upstream branch.
- The menu bar item on macOS shows the state of each agent and the quota of Claude and Codex, with colored status dots.
- New windows: agent information, custom scripts, and an Agents section in Settings.
- Heidrun remembers the window position and size, and the selected workspace, and restores them at the next start.
- New settings: the default command of a new tab, and questions before a tab, a workspace, or a note is closed.
- Both sidebars collapse to an icon bar. The panes meet each other with square corners, the selected pane is easier to identify, and the colors follow Visual Studio Code Dark Modern and Light Modern.
- You can drop an image onto a terminal to paste it, and reorder tabs, workspaces, and notes with the mouse.
- An empty tab shows a baby goat and a joke, and the About window, the splash screen, and the empty tab have goat sounds. The command line option `--no-splash-screen` starts Heidrun without the splash screen.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
