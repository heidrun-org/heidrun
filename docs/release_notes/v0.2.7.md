## What is new in 0.2.7

- The sidebar has three new sidebar sections: the Code hosting sidebar section, with the issues and the pull requests of GitHub or GitLab and saved searches, the User activity sidebar section, and the Launchers sidebar section, which replaces the Scripts sidebar section and imports the scripts of every `package.json` of the repository.
- The new Statistics window, in the More menu, has two tabs: "User activity", with a histogram of the user activity time stacked by workspace, and "Work of one person", with the Git history or the AI cost of one person for each day.
- The Past chats sidebar section, which replaces the Chats sidebar section, shows the tokens, the estimated cost, and the worktree names of each chat, and the Settings window has an option to switch off the dynamic topics.
- The File explorer sidebar section, which replaces the Files sidebar section, has a context menu on the row of each file and each folder, and an option to show the files that Git ignores.
- The Clipboard sidebar section replaces the Notes sidebar section, and the Needs you sidebar section shows the list of workspaces at its bottom.
- The top bar has a Back button and a Forward button to go through the panes that had the focus, and each pane shows its context window as a usage wheel.
- The coding agent Antigravity is in the list of coding agents, and Heidrun reads the models and the efforts of each coding agent from its own tool. The window Find new skills installs a skill from the web address of a skill folder on GitHub.
- A tab switch keeps the terminals of the opened tabs alive, so the terminal does not blink. A new pane, a new tab, and a new workspace start the default command of a new tab. The last tab of a workspace cannot be closed.
- Heidrun fetches the remote repository in the background, and the Settings window, rewritten with Bootstrap components, has the delay between two fetches.
- The window About Heidrun shows the date and the time of the build after the version, and each abbreviated time, such as "Just now", has a circled question mark that shows the exact time.

The complete list of changes is in the file `CHANGELOG.md`.

The disk image is not signed, not notarized, and built only for the architecture of the machine that builds it.
