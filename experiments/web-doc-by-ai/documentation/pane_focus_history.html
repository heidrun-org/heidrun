Go back and forward through the panes that had the focus ​

Return to a pane that had the keyboard focus earlier, and move forward again, with the buttons or the keyboard shortcuts.

Before you start ​

A pane is one terminal inside a tab. The pane that has the keyboard focus is the pane that receives what you type.

Heidrun keeps one pane focus history for the whole window. The history covers all workspaces and all tabs, and it is empty when Heidrun starts.

Where the buttons are ​

The Back button (left arrow) and the Forward button (right arrow) are in the top bar, at the very top of the window, just left of the search button.

Go back or forward one pane ​

  1. Click Back to focus the previous pane, or click Forward to focus the next pane.
  2. Heidrun selects the workspace and the tab of that pane.
  3. Check that the destination pane has the keyboard focus.

Choose a pane from a list ​

  1. Hold the Back button or the Forward button for about half a second, until a list opens below the button.
  2. Release the button. The list stays open, and the release does not move you.
  3. Read the list. The Back list shows earlier panes, and the Forward list shows later panes. The nearest pane is first.
  4. Click a row to focus that pane and close the list.

Each row starts with the workspace, then the tab. The agent type and the custom name of the pane may follow when they are different from the earlier parts. Names that repeat are left out, so two rows can look the same.

Close the list ​

  • Press Escape. The list closes without selecting an entry, and the keyboard focus returns to the button that opened it.
  • Click outside both the list and the button that opened it. The list closes, but the click still acts on the element that you clicked and may focus the clicked pane.

Use the keyboard shortcuts ​

Press ⌘[ to go back and ⌘] to go forward. Heidrun matches the characters "[" and "]", so the shortcuts work on a French keyboard. The full list of shortcuts is on the Keyboard shortcuts page.

A pinned pane gets the focus where it is, and the tab that you are on does not change.

Use the shortcuts when the file explorer is open ​

The file explorer is the window that opens with ⌘P. It shows a file tree and an editor, and its title is Files. It is not the large Git window that opens from the Files sidebar section. While the file explorer is open, ⌘[ and ⌘] do nothing, because the file explorer keeps them for its editor.

  1. Close the file explorer with the X button; its tooltip is “Close the file browser (Escape)”. This is the reliable way to close it.
  2. If some files have unsaved changes, choose one of the three answers that Heidrun offers.
  3. Confirm that the file explorer has closed before trying ⌘[ or ⌘] again, and check that the matching direction is available.

You can use Escape only when the editor does not have the keyboard focus and no menu, naming mode, selected row, diff, or search text is using the key. Otherwise, use X.

ChoiceWhat happens
Save all and closeHeidrun saves every file, then closes the file explorer. If a save fails, the file explorer stays open on the file with the error.
Discard the changesHeidrun closes the file explorer and the unsaved changes are lost.
CancelThe file explorer stays open and the navigation stops.

Troubleshooting ​

Back button is disabled ​

Cause: No earlier entry exists before the current entry in the pane focus history.

Solution:

  1. Focus one pane and keep keyboard focus on that pane for at least half a second.
  2. Focus a different pane, keep both panes open, and keep keyboard focus on the different pane for at least half a second.

Check: The Back button is enabled.

Forward button is disabled ​

Cause: No later entry exists after the current entry in the pane focus history.

Solution:

  1. First follow the steps for a disabled Back button so that an earlier entry exists.
  2. Click Back once.
  3. Do not focus a new pane after moving Back.

Check: The Forward button is enabled.

The history is missing or empty ​

Cause: Normal focus changes are recorded after a pane keeps the focus for about half a second, and the history is empty when Heidrun starts; before moving, Back, Forward, and choosing a history entry record the currently focused pane immediately, even if it has not yet been recorded.

Solution:

  1. Focus one pane and keep keyboard focus on that pane for at least half a second.
  2. Focus a different pane, keep both panes open, and keep keyboard focus on the different pane for at least half a second.
  3. Hold the enabled Back button to open the earlier list.

Check: The list shows the first pane.

The shortcut ⌘[ or ⌘] does nothing ​

Cause: The file explorer may use the shortcut, or it may still be open because Cancel returned you to editing.

Solution:

  1. Close the file explorer with X. Use Escape only when the editor does not have the keyboard focus and no menu, naming mode, selected row, diff, or search text is using the key.
  2. If Heidrun asks about unsaved changes, choose Save all and close to save and close, or Discard the changes to close and lose those changes.
  3. If saving fails, leave the file explorer open on the file with the error; do not expect the shortcut to work yet.
  4. If you choose Cancel, return to editing and stop here; the file explorer remains open, so do not try the shortcut again.
  5. After choosing a closing option, confirm that the file explorer has closed and that the matching Back or Forward direction is available before retrying the shortcut.

Check: The file explorer is closed and the matching direction is available before you retry; after retrying, the focus moves to the pane in that direction.
