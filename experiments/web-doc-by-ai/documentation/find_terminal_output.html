Find text in terminal output ​

Search recent terminal output, then select a matching line to return to its pane.

Search the terminals ​

A pane is one terminal inside a tab.

  1. Press Command+Shift+F to open Search in the terminals. Alternatively, click Search, run a command… in the top bar or press Command+K to open the command palette, then choose Search in all terminals….
  2. Enter at least two characters in the search field. Plain text searches ignore letter case and accents; leave .* (Regular expression) unchecked when punctuation should be treated as ordinary text.
  3. Check the current filter settings before reading the results. This workspace limits results to the selected workspace; when it is unchecked, panes across workspaces are searched. Agents only excludes ordinary shell panes, and .* (Regular expression) changes how the search text is interpreted; these settings are remembered.

Results are grouped by pane name and show matching lines with nearby terminal text. The search checks up to 3,000 recent lines from each current pane; it does not search project files or an unlimited archive. The number of results counts matching lines, including command echoes, so it may be larger than the number of commands that printed the text.

Open a matching line ​

  1. Find the pane group that contains the line you want.
  2. Select the matching line itself, rather than the pane group heading. Search closes and Heidrun selects the workspace, tab and pane that own the line.

Heidrun attempts to scroll to and highlight the matching text when that line is still available in the pane. If the text is no longer available, the pane may not show the match.

Troubleshooting ​

No results appear ​

Cause: The query is too short, the text is absent from recent pane output, or a filter excludes the pane or changes how punctuation is read.

Solution:

  1. Enter at least two characters and check the spelling against the terminal output.
  2. Check whether This workspace is limiting results to the selected workspace.
  3. Clear Agents only if the output came from an ordinary shell pane.
  4. Clear .* (Regular expression) if you want punctuation to match literally.

Check: Matching lines appear beneath their pane group when the text is in the searched output and the filters include that pane.

The latest terminal output is missing ​

Cause: The search can reuse output already read while the dialog is open, and it cannot search beyond the recent history available from each pane.

Solution:

  1. Press Escape to close Search in the terminals, then press Command+Shift+F to reopen it and refresh the output used by the search.
  2. Search for a distinctive phrase from the recent output, which must still be in the pane's available history.

Check: The refreshed search shows a matching line if the line remains in the pane's available recent output.

The selected result is higher in the history ​

Cause: Heidrun could not find the selected line in the pane's currently available terminal history to scroll to and highlight it.

Solution:

  1. Scroll up in the selected pane to look for the matching line in its earlier output.

Check: The matching line is visible in the pane if it remains in the available terminal history.
