Files sidebar section controls ​

Look up the controls, appearance choices, and row indicators of the Files sidebar section.

Header buttons ​

The header stays at the top while the rows scroll. The five buttons show only icons, in this order from left to right.

ButtonIconPurpose
New fileFile with a plus signOpens a name box for an empty file in the selected destination.
New folderFolder with a plus signOpens a name box for an empty folder in the selected destination.
RefreshCircular arrowReads the folder tree again; disabled while the folder tree loads.
Collapse all foldersSquare with a minus signFolds every folder.
More optionsThree vertical dotsOpens the appearance choices for the folder tree.

There is no button to unfold every folder.

Row and name box actions ​

ActionResult
Click a folder rowSelects the folder and folds or unfolds the folder, unless the folder is ignored.
Click a file rowSelects the file and opens the file in the large Git window.
Right-click a file rowOpens the file context menu without opening the large Git window.
Click empty space outside all rowsClears the selection in the selected workspace.
Press Enter in the name boxCreates the file or folder for a valid, nonempty name; an error keeps the name box open.
Press Escape in the name box, or click outside the name boxCancels creation.

More options ​

A check mark identifies the active choice in each group. The appearance choices are saved.

GroupChoicesDefaultMeaning
IndentationSmall, Medium, LargeMediumThe horizontal space added for each folder level.
Row heightCompact, ComfortableComfortableThe vertical space occupied by each row.
Indent guidesShow, HideShowWhether lines mark the folder levels.

File context menu ​

A context menu is a small menu of actions for a row. These items are available for file rows only.

ItemCopied text
Copy absolute pathThe full path of the file.
Copy relative pathThe path of the file relative to the Git repository root, including when the workspace folder is a repository subfolder.

See Copy a file path for examples and copying steps.

Folder tree indicators ​

Folders appear before files, with each group in alphabetical order.

IndicatorMeaning
Right-pointing folder arrowThe folder is folded.
Downward-pointing folder arrowThe folder is unfolded.
Row with a blue outlineThe selected file or folder; only one row is selected.
MA modified file.
AAn added file.
DA deleted file.
RA renamed file.
UA new file that Git does not track yet.
Dot on a folder rowChanges exist inside the folder.

Changed-file letters appear at the right of the file row.

Selection ​

ItemMeaning
Selected rowEach workspace keeps a separate selection. Returning to a workspace restores the selected row with the folders above the row unfolded.
Closing the large Git windowThe selected row remains selected.
Changing the sidebar sectionThe selected row and the folded or unfolded state of folders are retained.

Ignored files ​

The Files window is the project file browser opened with ⌘P, as listed in Keyboard shortcuts. The Ignored files checkbox is below the file-name search field in the Files view on the left of the Files window.

The choice is saved and also affects the Files sidebar section. Folders excluded by .gitignore appear when the checkbox is selected, but cannot unfold.

See Create a file or folder for empty-folder behaviour and Browse and open project files for the long-list limitation.
